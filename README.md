# AI Radar 📡


AI Radar is an automated newsletter that collects the latest AI updates from leading tech companies, generates concise summaries using Google's Gemini 2.5 Flash, and delivers them straight to your inbox.

## ✨ Features
- Fetches news through RSS feeds.
- Tracks updates from OpenAI, Google, Anthropic, NVIDIA, Microsoft AI and Meta AI.
- Generates AI-powered news summaries using Gemini 2.5 Flash.
- Delivers a curated daily newsletter via email.

## 🛠️ Tech Stack
- Google Apps Script
- JavaScript
- RSS Feeds
- Gemini 2.5 Flash API
- Gmail

## ⚙️ How It Works
1. Fetches recent articles from selected RSS feeds.
2. Filters and processes relevant news.
3. Uses Gemini to generate concise summaries.
4. Compiles the stories into an email newsletter.
5. Delivers the briefing to your inbox.

## 🔐 Security
API keys are stored in Google Apps Script Properties and sensitive configuration files are excluded from version control.

## 🎯 Objective
To simplify staying updated on the rapidly evolving AI landscape through automation and AI-powered summarisation.
